# Antonio Rentería

Combino experiencia técnico-comercial con el desarrollo de aplicaciones y herramientas con IA. Me interesa convertir problemas cotidianos y de negocio en soluciones que sean fáciles de usar.

## Proyecto destacado: Misal MX

[Misal MX](https://misalmx.com) es un proyecto personal para seguir la misa y consultar recursos de oración desde el celular o el escritorio.

Nació de una necesidad concreta: poder ampliar el texto y seguir las lecturas con comodidad. A partir de esa primera experiencia, el proyecto incorporó una propuesta para niños, oraciones y recursos para acompañar la vida de fe.

**Qué puedes explorar:** misal por fecha, Peques, biblioteca de oraciones, Rosario y examen de conciencia.

[Conocer la historia del proyecto](https://misalmx.com/acerca-de)

## Otros proyectos seleccionados

**Mathix** — Plataforma de aprendizaje de matemáticas que contempla experiencias para escuelas, docentes y alumnos, con ejercicios y seguimiento del progreso.

SalesGPT y Mathix se presentan por su alcance documentado; sus demostraciones públicas están pendientes. Los casos no incluyen código ni datos internos.

## Cómo trabajo

- Parto del problema y del flujo que necesita la persona que usará la solución.
- Utilizo IA para apoyar el desarrollo y la iteración.
- Doy especial atención a la claridad, la lectura y la experiencia en móvil.
- Distingo lo que está construido de lo que todavía necesita pruebas o validación.
